# Перенос MixControl с текущими данными на рабочий ПК

Исходники: https://github.com/EvillHamster/MixControl---V1.0

## Что взять с собой

- Доступ к репозиторию GitHub.
- Отдельный файл backups/transfer-work-pc-2026-11-09.json из текущей папки проекта. Он НЕ хранится в GitHub. Перенесите его на флешке или другим согласованным защищённым способом.
- Ваш прежний логин и пароль приложения. Пользователи и хеши паролей сохраняются; действующие сессии не переносятся.

Снимок содержит данные на момент его создания. Более поздние изменения в него не попадут. Снимок содержит персональные данные и хеши паролей; не публикуйте его.

## На рабочем ПК

Установите Git for Windows, Node.js 24 и откройте VS Code. В терминале:

~~~powershell
git clone https://github.com/EvillHamster/MixControl---V1.0.git MixControl
cd MixControl
npm.cmd ci
Copy-Item .env.example .env
npm.cmd run db:local
~~~

Последняя команда запускает PostgreSQL. Оставьте этот терминал открытым. Скопируйте файл transfer-work-pc-2026-11-09.json в папку backups внутри клонированного проекта (создайте папку, если её нет).

Откройте ВТОРОЙ терминал VS Code в той же папке проекта:

~~~powershell
npm.cmd run db:migrate
node scripts/database-snapshot.mjs restore backups/transfer-work-pc-2026-11-09.json
npm.cmd run dev
~~~

Откройте http://127.0.0.1:5173 и войдите со СТАРЫМ логином и паролем.

**До восстановления не создавайте KEYUSER и не вводите новые данные.** Восстановление разрешено только в пустую базу; если база уже заполнена, команда остановится без перезаписи. Не удаляйте существующие рабочие базы для обхода проверки.

Если исходники скачаны ZIP, начните с открытия распакованной папки в VS Code, затем выполните команды начиная с npm.cmd ci. Если .env уже есть и вы его настраивали, сохраните его и проверьте DATABASE_URL; не перезаписывайте настройки внешней базы.

## Следующие запуски

Остановите приложение и ручной PostgreSQL через Ctrl+C в обоих терминалах. В дальнейшем достаточно:

~~~powershell
npm.cmd run dev
~~~

Команда сама запускает стандартную локальную PostgreSQL. Данные сохраняются в .postgres. Две установки на разных ПК независимы; GitHub синхронизирует код, но не рабочие данные.
